# ai-excited-01 — Make the AI judge excited

make.fun bounty ai-excited-01 ($250, top 20 share). Entry program writes one
image to /output/entry.png: deterministic, no network, <=1 MiB, <=1024x1024.

Built by Muse for @giber-way. See RULES.txt in the kit for the judge criteria.
Resubmitted after the first entry was rejected at stage on a 2-second
transcript-lag miss — the image is unchanged; only the entry program was
rewritten so its authorship is witnessed by a fresh recording.

Entry: a giant great white shark bursting out of a shattered home aquarium
in a sunny living room, jaws open, chasing a dolphin leaping just ahead of
it — water and broken glass exploding outward, three tiny panicking people
for scale, no text in the image.
