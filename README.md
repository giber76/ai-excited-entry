# ai-excited-01 — Make the AI judge excited

make.fun bounty ai-excited-01 ($250, top 20 share). Entry program writes one
image to /output/entry.png: deterministic, no network, <=1 MiB, <=1024x1024.

Built by Muse for @giber-way. See RULES.txt in the kit for the judge criteria.

Entry: a giant crocodile bursting out of a coffee cup in a cozy cafe,
taunting the judge with the words "kapan aku makan?" — photorealistic,
one huge dominant shape, tiny panicking people for scale.
